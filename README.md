# Folio – WordPress Block Theme

A minimal block (FSE) theme for portfolios and personal sites. No page builder, no jQuery.

**Live demo:** see the demo repo linked below.

## Features
- `theme.json` design system: colour palette, fluid typography, spacing scale
- Templates: blog index, single post, page, 404
- Template parts: header, footer
- Block patterns: Hero, Projects grid
- Root-padding-aware alignments, responsive navigation

## Install
Download the repo as a zip and upload it at **Appearance → Themes → Add New → Upload Theme**, or clone into `wp-content/themes/folio-block-theme`.

Requires WordPress 6.4+ and PHP 7.4+.
